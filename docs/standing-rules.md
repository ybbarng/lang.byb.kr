# 이 저장소에서 정한 규칙

사용자가 정한 것. 새 규칙은 같은 주제의 줄을 찾아 고친다.

- 홈은 언어별 공부 사이트로 가는 가벼운 링크 모음이다. 교재 자료는 각 공부 사이트에 두고 여기 두지 않는다. (2026-11-23)
- 그래도 언어 공부에 대한 꿈이 보이는 페이지로 만든다. 지금은 배우는 말, 곧 시작할 말, 언젠가 배울 말 세 칸으로 나눈다. (2026-11-23)
- 폰(안드로이드)과 데스크탑 모두에서 보기 좋고 편해야 한다. 화면을 고치면 두 너비(393px, 1280px)로 찍어 확인한다. (2026-11-23)
- 언어 목록과 주소는 `src/lib/languages.ts` 한 곳에만 둔다. (2026-11-23)
  - 프랑스어: study-fr.byb.kr. ftf.byb.kr은 301로 넘어간다.
  - 일본어: study-ja.byb.kr, 2027-01-01 시작.
  - 앞으로 스페인어·이탈리아어·독일어·중국어 등이 더해질 수 있다.
- 배포처는 byb.kr 서버다. Vercel은 쓰지 않는다. 서버 쪽 설정(`servers` 저장소 `byb.kr/apps/lang/`, Traefik, DNS)은 servers 세션이 맡고, 비서를 거쳐 부탁한다. (2026-11-23)
- 이 저장소의 main push는 곧 운영 배포다(GitHub Actions). push는 사용자 승인 범위 안에서만 한다.
